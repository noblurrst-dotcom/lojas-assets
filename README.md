# lojas-assets

CSS e JS das lojas Tray do grupo, servidos de graça pelo GitHub Pages:

- Loja do Detalhamento: `ld/ld-loja.css`, `ld/ld-loja.js`
- IGL Coatings Brasil: `igl/igl-loja.css`, `igl/igl-loja.js`

Endereço: `https://noblurrst-dotcom.github.io/lojas-assets/<pasta>/<arquivo>`

Para mudar a loja: editar aqui, commit e push na `main`. O Pages publica em cerca de 1 minuto (cache do navegador: 10 minutos). Sem deploy no Netlify.
Os endereços antigos (`ld-loja-assets.netlify.app/ld-loja.*` e `www.iglcoatings.com.br/assets/loja/igl-loja.*`) redirecionam para cá.
